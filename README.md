# Recipe App 🍳

A responsive web application for browsing and discovering delicious recipes. Built with vanilla HTML, CSS, and JavaScript with full mobile responsiveness using media queries.

## 📋 Features

- **Recipe Browsing**: View a collection of recipes with images and descriptions
- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Interactive UI**: Dynamic recipe cards with hover effects and smooth transitions
- **Recipe Details**: View detailed cooking instructions, ingredients, and preparation time
- **Clean Interface**: Modern, user-friendly design with intuitive navigation

## 🚀 Technologies Used

- **HTML5**: Semantic markup for better structure and SEO
- **CSS3**: Modern styling with Flexbox/Grid layouts
- **JavaScript**: Dynamic functionality and user interactions
- **Media Queries**: Responsive design for all screen sizes

## 🖥️ Responsive Breakpoints

The app is optimized for the following screen sizes:

- **Mobile**: 320px - 480px
- **Tablet**: 481px - 768px
- **Laptop**: 769px - 1024px
- **Desktop**: 1025px and above
